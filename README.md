# Robotics Capstones

My path to learning/remembering robotics, one robot at a time. Each capstone is independent and harder than the one
before, and is built end to end: electronics, mechanics, code, photos and videos. Each one lives in its own
repository.

From the Spider-Bot on, each robot has a **build log** (the story step by step, dead ends included, so it can be
repeated) and an **AI log** (what was designed with AI help and how it was checked).

| # | Capstone | Robot | What I learn | Status |
|---|---|---|---|---|
| 0 | [Arduino Starter Kit R4](https://github.com/Morante-robotics/arduino-starter-kit) | Projects from the Arduino Projects Book; Arduino Certification: Fundamentals passed | Basic electronics, microcontroller programming: PWM, ADC, interrupts, sensors | Done |
| 1 | [Spider-Bot replica](https://github.com/Morante-robotics/spider-bot-replica) | Replica of the Avengers Campus Spider-Bot: 8 legs driven by one motor, LED eyes, walks when switched on | Soldering, CAD and 3D printing, linkages and gears, motor and battery sizing | In progress |
| 2 | Quadruped | SpotMicro remixed for 12 bus servos, walking with a learned policy and following natural-language orders | ROS 2, simulation (MuJoCo), reinforcement learning, sim-to-real, VLM planning | Planned |
| 3 | Humanoid | Humanoid based on an open-source design, modified | Reinforcement learning in simulation, robot foundation models | Planned |

Videos of the builds: [youtube.com/@morante-robotics](https://www.youtube.com/@morante-robotics).
